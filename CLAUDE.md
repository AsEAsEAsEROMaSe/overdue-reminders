# Правила проєкту для агента

- Мова відповідей і звітів: українська. Коментарі в коді короткі, українською.
- Код простий, рівня junior: звичайні функції, цикли, if, зрозумілі назви. Без зайвих абстракцій.
- Код багаторядковий: кожна дія окремим рядком, if завжди з дужками на окремих рядках, без тернарників, без ланцюжків в один рядок, без && замість if.
- Кожен файл у src/ і test/ має шапку JSDoc (@file, @module, @see {@link ...}) з повними списками «Головний» (хто його імпортує) і «Нижчі» (кого імпортує він). Змінив import: онови шапки обох файлів. Формат у BRIEF.md.
- Стек: TypeScript strict, Node 20+, ESM, vitest. Нових залежностей без дозволу не додавати.
- Команди: `npm install`, `npx vitest run`, `npx tsc --noEmit`.
- Перед кодом план, чекати підтвердження. Малі кроки, кожен з перевіркою.
- Спершу тест, що падає, потім код.
- Агент пише, відповідає людина: «готово» лише з виводом тестів і tsc.
- Звіт завжди: зроблено, перевірено, лишилось, припущення.
- Заборонено: пуш, force push, видалення файлів поза задачею, токени й справжні chat_id у коді чи логах, зміна очікувань у тестах заради зеленого.
- Тричі не виходить: зупинитись і описати проблему.
